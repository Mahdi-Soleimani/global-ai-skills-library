# Code of conduct

GASL welcomes contributors of all experience levels and backgrounds.

## Expected behavior

- Discuss technical ideas respectfully and constructively.
- Review code and documentation on their merits.
- Respect privacy, upstream authorship and licensing.
- Do not harass, discriminate, threaten, impersonate or publish private information.

Maintainers may remove inappropriate content, close discussions, or restrict participation when necessary. Use the repository's private vulnerability-reporting channel if enabled for security issues; otherwise contact the maintainer privately without posting sensitive details.

This policy applies to repository issues, discussions, reviews and pull requests.
