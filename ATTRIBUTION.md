# Third-party attribution policy

Global AI Skills Library (GASL) is a discovery, indexing, and aggregation project. It does not claim authorship, exclusive ownership, or original creation of third-party skills.

For every discovered source record, GASL preserves the upstream repository, original path, source URL, repository owner/publisher, observed license metadata, and—when available—the exact commit, tree, and file blob identifiers. The repository owner is not automatically treated as the individual author. Individual authors are recorded only when supported by source evidence.

The complete source index includes discovered skills regardless of license status. A source appearing in the index does not mean GASL owns it or that its contents may be redistributed.

Public content mirrors are limited to packages that pass the configured license allowlist and include the applicable upstream LICENSE/COPYING/NOTICE evidence. Original files are kept unchanged and each mirrored package receives an ATTRIBUTION.md and ATTRIBUTION.json. The source catalog retains links for all other entries, including entries with missing, unknown, proprietary, or unreviewed license information.

Attribution is not a substitute for permission. A public repository, a source link, or a credit line alone does not grant redistribution rights. Original rights holders and their license terms remain authoritative.

No downloaded skill is automatically installed or executed. A successful integrity or static scan is not security approval.
