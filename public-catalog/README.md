# GASL Public Catalog

This directory contains version-pinned third-party skill packages whose repository-level license signal is on the configured redistribution allowlist and whose upstream license/notice evidence is bundled. Every package includes ATTRIBUTION.md and ATTRIBUTION.json. GASL is a discovery and aggregation project; it does not claim authorship or exclusive ownership of these works. The original author/rightsholder and upstream license remain authoritative.

A clean static scan is not a security approval. Packages are not installed or executed by this workflow. Sources with unknown, missing, proprietary, non-allowlisted or unverified licensing remain listed in registry/source-catalog.json with their original source links; their content is not mirrored here automatically.
